# Benchmark data archive

This directory centralizes the benchmark files recovered from the historical A-CLA project.

## `adjacency_matrices/`

Contains the 15 labeled adjacency matrices corresponding to the networks enumerated in Table 5.1 of the final manuscript. The manuscript abstract states that sixteen networks were evaluated, while Table 5.1 contains fifteen rows. This repository preserves the table and recovered files as-is and documents the mismatch.

## `network_tables/`

Contains recovered node/edge-format workbooks used by several historical scripts. Not every network had a separate node/edge-format workbook in the archive.

## Data provenance

These files were recovered from the authors' experiment directory. Original upstream download URLs and dataset-specific licenses were not consistently stored alongside every matrix. They are therefore presented as a reproducibility archive rather than as a claim of ownership over third-party datasets. Researchers redistributing individual benchmark datasets should verify the corresponding original dataset terms.
