# Experiments

This directory provides experiment-entry documentation. Historical executable scripts remain under `legacy/`; clean reruns use the `acla` package.

- `01_nonoverlap_modularity/` — primary modularity-oriented A-CLA path.
- `02_nmi/` — historical NMI comparison scripts and table mapping.
- `03_f1/` — historical F1 provenance; see known limitation before interpreting.
- `04_structural_metrics/` — edge density and betweenness centrality.
- `05_overlap_exploratory/` — exploratory overlap-aware comparisons.
- `06_convergence/` — convergence reference data.
- `07_statistics/` — ANOVA, Tukey HSD, and SD outputs.
