# Contributing

This repository is primarily a reproducibility archive for a published study. Contributions are welcome when they improve portability, testing, documentation, or clearly identified extensions without rewriting historical provenance.

Please follow these principles:

1. Do not edit files under `legacy/` in place. They are archival snapshots.
2. Put maintainable changes in `src/`, `scripts/`, `tests/`, or `docs/`.
3. Distinguish a bug fix from an algorithmic change.
4. Add or update tests for code changes.
5. If a change can alter published numerical outcomes, document it explicitly in `docs/PROVENANCE_AND_KNOWN_LIMITATIONS.md`.
