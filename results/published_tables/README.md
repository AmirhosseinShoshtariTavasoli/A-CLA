# Published table transcriptions

These CSV files are machine-readable transcriptions of Tables 5.1-5.6 where the final manuscript contains tabulated values. F1-score results are presented graphically in Figure 5.6 rather than as a numerical table in the manuscript, so no invented F1 table is included here.

The CSVs are **transcriptions of the manuscript**, not newly recomputed results. Historical Excel workbooks that supported analysis are preserved under `../reference_archive/`.
